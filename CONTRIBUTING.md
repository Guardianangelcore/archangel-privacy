# Contributing Guide

Thanks for helping improve Archangel Privacy.

## Code of Conduct

Maintain a respectful, professional, and inclusive environment for all contributors.

## Security Requirements

- Do not commit secrets or credentials
- Follow privacy best practices
- Do not expose personal data
- Review security guidelines in SECURITY.md

## Pull Request Checklist

- No secrets committed
- Security checks pass
- Documentation updated when needed
- PR reviewed by an owner
- Complies with privacy standards

## Reporting Security Issues

Please email security@guardianangel.dev and do not open a public issue for vulnerabilities.
